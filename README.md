# Memory Quiz Game 🧠

A Python-based Memory Quiz Game that tests the user's ability to remember and reproduce a sequence of items.

## Features

- Generates a random sequence
- Displays the sequence temporarily
- Hides the sequence
- Takes the user's answer
- Checks the order of items
- Calculates the score
- Displays performance

## Technologies Used

- Python
- Random
- Time
- Lists
- Loops

## How to Run

```bash
python memory_quiz_game.py
